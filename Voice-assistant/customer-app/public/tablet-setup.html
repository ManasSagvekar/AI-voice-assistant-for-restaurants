Set up this tablet

The assistant needs the microphone, and browsers only allow that on a secure connection. Do this once on each tablet, so it trusts this restaurant's own computer.

1. Download the certificate

Download certificate

2. Install it

Android:

  1. Open Settings and search for Install a certificate (or go to Security, then Encryption & credentials).
  2. Choose CA certificate, then Install anyway.
  3. Pick the downloaded file, tablet-ca.crt.

iPad:

  1. Open Settings, then Profile Downloaded, and install it.
  2. Go to General, then About, then Certificate Trust Settings, and switch it on.

3. Open the restaurant

Close and reopen the browser first. Then choose this tablet's table; it stays with this table until staff release it.

Continue to the tables

If you skip the certificate, the browser shows a warning you can click through, and it asks for the microphone again more often.
